# 임상 데이터 스크리닝

임상 연구 원자료(엑셀)에서 오타/허용 범위 밖의 값/형식 오류 등을 자동으로 찾아 주고, 웹 화면에서 바로 고친 뒤 저장하는 도구입니다.

## 주요 기능

- **자동 검사**: 엑셀 파일을 올리면 공통 검사(결측, 공백, 숫자 오타, 표기 차이)와 연구별 규칙 검사를 한 번에 실행합니다.
- **데이터 표에서 확인**: 시트 전체를 엑셀처럼 보여 주고 문제 셀을 등급별 색으로 표시합니다.
  같은 대상자의 다른 방문 값처럼 주변 셀과 비교하면서 원래 값을 판단할 수 있습니다.
- **그 자리에서 수정**: 셀을 고르고 값을 입력해 [수정하기]로 확정하고, [반영하고 다시 검사]로 문제가 사라졌는지 바로 확인합니다.
- **수정 기록 남기기**: [수정한 파일 저장]으로 내려받은 엑셀에는 수정된 시트와, `Change_Log` 시트에 수정 시각, 셀, 수정 전·후 값, 문제 유형이 기록됩니다.
- **규칙 편집**: 각 데이터별 검토해야할 값의 숫자 범위, 허용값, ID 형식, 연구 기간, 컬럼 간 조건을 화면에서 만듭니다. 편집 내용은 브라우저에 자동 저장되어 바로 적용되고, JSON 파일로 내보내 다른 연구자와 공유할 수 있습니다.
  데이터를 불러오면 컬럼별 값 분포를 보고 규칙 초안을 자동으로 만들어 줍니다.
- **결과 리포트**: 요약, 문제 목록, 사용한 규칙, 원본 데이터를 담은 결과 엑셀을 내려받습니다.

## 데이터 보안

- 검사와 수정은 **사용자 PC의 브라우저 안에서만** 실행됩니다. 데이터는 서버나 외부로 전송되지 않습니다.
- 필요한 파일을 모두 포함해 배포하므로 **인터넷 연결 없이** 기관 내부 NAS에서 동작합니다.
- 원본 파일은 바뀌지 않습니다. 고친 내용은 `원본이름_corrected.xlsx`라는 새 파일로 저장됩니다.

## 검사 항목

| 검사                              | 등급      | 예시                                         |
| --------------------------------- | --------- | -------------------------------------------- |
| ID 형식 오류                      | 오류      | `subj-016`, `SUBJ17` (규칙: `^SUBJ-\d{3}$`)  |
| 중복 레코드                       | 오류      | 같은 대상자·방문 조합이 두 번 입력됨         |
| 날짜 변환 불가                    | 오류      | `2026-13-40`                                 |
| 숫자 컬럼의 문자 / 숫자 변환 불가 | 확인 필요 | `17O`, `130mg`, `8l`                         |
| 허용 범위 밖                      | 확인 필요 | 나이 `150`, SBP `300`                        |
| 허용되지 않는 값 / 표기 차이      | 확인 필요 | 성별 `X` / `m`, `Female`, `Yes`, `treatment` |
| 연구 기간 밖                      | 확인 필요 | 연구 기간 이전·이후 방문일                   |
| 컬럼 간 조건 위반                 | 확인 필요 | SBP가 DBP보다 작음                           |
| 앞뒤 공백, 빈 컬럼                | 확인 필요 | `␣72.5`                                      |
| 결측값                            | 정보      | 빈 셀                                        |

등급: **오류**는 반드시 고쳐야 하는 값, **확인 필요**는 연구자가 판단할 값, **정보**는 참고용입니다.
연구별 규칙의 예시는 [data/study_rules.json](data/study_rules.json)에 있습니다.

## 개발과 배포

개발환경: Python 3.14, Node.js 22

터미널 내 아래 명령어 입력으로 웹 실행이 가능합니다. 

```bash
python3 -m venv .venv && .venv/bin/pip install pandas openpyxl pytest
cd frontend && npm install && npm run dev    # http://localhost:5173
```

## 구조

| 경로                       | 역할                                       |
| -------------------------- | ------------------------------------------ |
| `backend/src/`             | 검사 로직 (터미널과 웹이 같은 코드를 사용) |
| `backend/src/validator.py` | 검사 항목별 규칙                           |
| `backend/src/editor.py`    | 셀 수정과 `Change_Log` 기록                |
| `backend/tests/`           | Python 테스트                              |
| `frontend/`                | 웹 화면 (React + Pyodide)                  |
| `data/`                    | 예시 규칙과 테스트용 합성 데이터           |
